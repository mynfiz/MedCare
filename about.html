Tentang MedCare

Mengenal lebih dekat prototipe platform apotek digital dan skrining edukatif kesehatan pernapasan

Proyek Akademik Mahasiswa

Apotek Online Modern & Skrining Edukasi

MedCare ("Teman Sehat Anda, Setiap Hari") adalah sebuah prototipe website interaktif yang dikembangkan sebagai bagian dari tugas akademik mata kuliah pemrograman web (Semester 3).

Tujuan utama proyek ini adalah menerapkan konsep dasar rekayasa web modern sisi klien (front-end) menggunakan teknologi murni tanpa dependensi rumit: struktur semantik HTML5, tata letak responsif CSS3, logika interaktif Vanilla JavaScript, serta persistensi data lokal menggunakan Browser LocalStorage.

Melalui MedCare, pengguna dapat menjelajahi katalog produk kesehatan, memfilter kategori, mengelola keranjang belanja dan produk favorit secara persisten, membaca artikel edukatif, serta memanfaatkan fitur unggulan Respiratory Symptom Checker (Skrining Deteksi Gejala Pernapasan) yang dirancang dengan prinsip keselamatan klinis yang bertanggung jawab.

🏥

Apotek Digital

Katalog obat demo lengkap dengan status stok, harga rupiah, dan penanda resep dokter.

🫁

Deteksi Gejala

Kuesioner 7 langkah berbasis aturan (rule-based) dengan prioritas peringatan gawat darurat (119/IGD).

⚡

100% Client-Side

Dapat dijalankan langsung di browser mana pun dan di-hosting gratis via GitHub Pages tanpa server backend.

🎯

Visi Proyek

Menghadirkan contoh implementasi antarmuka web kesehatan yang ramah pengguna, bersih, aksesibel, dan menjunjung tinggi etika penyampaian informasi medis tanpa klaim diagnosis sepihak.

🚀

Misi Proyek

  • Mengembangkan kode sumber yang bersih, terstruktur, dan mudah dipahami bagi mahasiswa yang sedang mempelajari web development.
  • Mengedukasi masyarakat mengenai pencegahan infeksi saluran pernapasan melalui artikel yang mudah dipahami.
  • Menerapkan prinsip keamanan data pengguna dengan tidak mengirimkan data sensitif apa pun ke server eksternal.

Teknologi & Arsitektur

Dibangun dengan standar web modern tanpa framework pihak ketiga

🌐

HTML5 Semantik

Struktur halaman berbasis standar aksesibilitas web (WAI-ARIA) dengan tag semantik yang jelas.

🎨

CSS3 Modern

CSS Variables, Flexbox, CSS Grid, efek transisi halus, dan desain responsif mobile-first.

⚙️

Vanilla JavaScript

Manipulasi DOM murni, event delegation, validasi formulir, dan mesin analisis logika kuesioner.

💾

Web LocalStorage

Menyimpan keranjang belanja dan preferensi favorit langsung di peramban pengguna secara persisten.

PENAFIAN AKADEMIK

Pernyataan Resmi Batasan Prototipe

Website ini dibuat secara khusus untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah pemrograman komputer. MedCare bukanlah apotek komersial sungguhan dan tidak berafiliasi dengan fasilitas kesehatan mana pun.

  • Seluruh transaksi, stok obat, keranjang belanja, dan pemesanan bersifat simulasi front-end belaka.
  • Fitur deteksi gejala tidak dapat dan tidak boleh dijadikan pengganti konsultasi, diagnosis, atau resep dari dokter berizin resmi.
  • Jangan menghentikan atau mengubah dosis obat yang sedang Anda konsumsi berdasarkan informasi yang disajikan di website ini.
